# Load & Performance Testing Challenge — Artillery

Performance and load testing scripts built with **Artillery** to measure response times, throughput, and system stability under load.

## 🧪 What it tests

- API endpoint response times under load
- Concurrent user simulation
- Throughput and error rate thresholds
- System behavior under stress conditions

## 🚀 Getting Started

**Prerequisites:** Node.js 14+

```bash
# Install Artillery globally
npm install -g artillery

# Run a load test
artillery run <test-config.yml>

# Run and generate HTML report
artillery run --output report.json <test-config.yml>
artillery report report.json
```
